# M5Stack 搖動擲骰

遊戲端透過 USB Web Serial 與 M5StickC Plus 雙向通訊：連線後裝置螢幕顯示附件 USB 圖示的逆時針 90° 版本；按住 A 鍵並搖動可擲骰，也可直接點擊遊戲畫面上的「擲骰子」按鈕。擲骰後可用 B 鍵切換畫面選項，再按 A 鍵確認。

## 使用方式

1. 在 Arduino IDE 安裝 M5StickCPlus 函式庫，將 [硬體範例](../hardware/m5stickc-plus-dice/m5stickc-plus-dice.ino) 燒錄到 M5StickC Plus。韌體以加速度向量偏離重力偵測搖動；每次按住 A 鍵最多傳送一次擲骰事件，放開後可再次觸發。請依實機調整閾值。
2. 使用支援 Web Serial 的桌面 Chrome 或 Edge，透過 localhost 或 HTTPS 開啟遊戲，接上 USB 資料線。
3. 按遊戲右上方「連接 M5Stack」，選取裝置的序列埠。序列埠以 115200 baud 傳輸；遊戲端連線／斷線命令為 `CONNECT`／`DISCONNECT`，裝置事件為 `SHAKE`、`NEXT`、`SELECT`，皆以換行結尾。
4. **擲骰方式一：按住 M5StickC Plus 的 A 鍵並搖動**，裝置偵測後立即擲骰並顯示骰子動畫。**方式二：直接點擊遊戲畫面的「擲骰子」按鈕**，不需要連接或操作 M5Stack。
5. 擲骰完成進入落地選項後，按側面 B 鍵依畫面由上至下、同列由左至右循環切換；目前選項會有外框並顯示選項序號。按正面 A 鍵確認／點擊目前選項。打開操作視窗後，同一組按鍵也可切換並確認視窗內按鈕。
6. 其他玩家回合、移動中、等待落地選擇、遊戲結束或不具操作權限時，裝置搖動和選單事件不會操作遊戲。連線房間仍由伺服器決定骰點。
7. 中斷或拔除裝置後，遊戲畫面的按鈕仍可正常擲骰及操作；重新連線不會補送先前事件。

此連線需要瀏覽器支援 Web Serial；iOS 與部分手機瀏覽器不支援。瀏覽器連線及控制按鈕與 M5Stack 感測器韌體是兩個部分，遊戲不會自行燒錄韌體。

## 訊號與行為

- 序列埠以 115200 baud 收發換行分隔的純文字；遊戲下行 `CONNECT`／`DISCONNECT` 控制螢幕圖示，裝置上行 `SHAKE`、`NEXT`、`SELECT`。搖動訊號有 750 ms 去彈跳。
- 收到 `CONNECT` 時顯示旋轉後的 USB 圖示；收到 `DISCONNECT` 時清除畫面。重新連線會重新顯示圖示。
- A 鍵按住時每次最多傳送一次搖動事件；短按並放開 A 鍵送出 `SELECT`。側鍵 B 每按一次送出 `NEXT`。
- 選項按目前畫面位置排序，`NEXT` 移動焦點及高亮框，`SELECT` 點擊焦點。自己可操作的落地／視窗階段才接受選項事件。
- 搖動事件不含骰點，結果由既有遊戲引擎或多人房間伺服器產生；畫面擲骰按鈕始終可直接使用。
- Web Serial 需瀏覽器使用者手勢授權序列埠。此版本沒有裝置身分配對；共用電腦時，連線中的裝置事件會套用到當前有權操作的玩家。
- 硬體範例以加速度向量大小偏離重力作判斷，門檻是原型值，須依實際裝置、握持方式及感測器調整。瀏覽器與解析器測試不等於已完成實機驗證。

## 驗收項目

- 連線後裝置螢幕顯示逆時針旋轉 90° 的 USB 圖示；斷線後清屏。
- 按住 M5Stick A 鍵並有效搖動只擲一次；畫面「擲骰子」按鈕連線與否都可直接擲骰。
- 落地選項可用 B 鍵依畫面順序移動高亮，A 鍵會觸發目前選項。
- 非本人回合、移動中、等待落地選擇或遊戲結束時不因搖動擲骰。
- 車輛骰子數仍由遊戲規則決定；多人模式的擲骰結果由伺服器同步。
- 裝置拔除後仍可用畫面按鈕直接擲骰；重新連線不重播舊事件。
- 使用實際 M5StickC Plus、目標瀏覽器及 USB 資料線驗證感測閾值和相容性。

參考：[Web Serial API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API)。不要將房間憑證、Wi-Fi 密碼或 API 金鑰寫入公開程式碼。
